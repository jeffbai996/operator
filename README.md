## Overview

- **Live viewport and manual takeover:** Stream the active browser tab or desktop surface alongside the conversation trace, with instant switch between autonomous execution and direct mouse/keyboard control.
- **Explicit approval gates:** Pause before purchases, bookings, account changes, or external submissions to present the merchant, destination, and total for human confirmation.
- **Mid-run steering:** Redirect an active run in place without losing browser state or conversation context.
- **Multi-surface support:** Operate across a persistent browser profile, an isolated sandbox desktop, or a confirm-gated host desktop.
